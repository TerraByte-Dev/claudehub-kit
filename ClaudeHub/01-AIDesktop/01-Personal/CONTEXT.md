# 01 — Personal  ·  CONTEXT

> The person's own projects: side projects, games, hobbies, odd experiments, life admin. One
> folder per project, each with a short `CONTEXT.md`.

Empty on purpose: folders get made when a project starts, not in advance. If they picked a
side project in the first-launch interview, setup made its folder here from
`../../02-Internals/00-setup/starters/side-project.md`.

- **Starting any project**: copy that starter in as the project's `CONTEXT.md` (it's generic:
  what it is, what done looks like, source of truth, first three steps) and fill it in with
  them. Don't invent a goal they didn't state.
- **Mixed seriousness is normal.** A project can be an odd idea to poke at or one that needs
  real research behind it. Ask which, once; for the second, the questions go to
  `../03-Research/` and the project links to the briefs.
- Games: if a project is built around a game (a guide, a tracker, a mod, a tournament plan),
  record the game's current patch or version in its `CONTEXT.md` and re-check it before
  trusting anything that depends on it.
- Rules for making any other one → `../CONTEXT.md`.
