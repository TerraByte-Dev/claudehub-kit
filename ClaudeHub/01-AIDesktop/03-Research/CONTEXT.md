# 03 — Research  ·  CONTEXT

> **The research desk.** Any question worth getting right: a platform rule, what a tool's plan
> really includes, a game's current meta, whether a download is safe. One folder per question,
> a brief at the end with sources and an honest confidence level.

## Identity
The person wants things researched properly, not answered from memory. This room turns a
question into a short, cited answer they can act on, and keeps it so the same question is never
researched twice. It serves work and personal questions alike; a project that needs an answer
links to the brief here instead of copying it.

## Inputs
| Resource | When | Why |
|----------|------|-----|
| `METHOD.md` | every new question | the research method: frame, sweep, read, verify, write |
| `INDEX.md` | every visit | has this been answered already, and is the answer still fresh? |
| `../ABOUT-ME.md` | when the answer depends on them (budget, hardware, goals, limits) | so the answer fits them, not an average person |

## Process
1. **Check `INDEX.md` first.** Already answered and still fresh → give the bottom line and
   link the brief. Answered but stale → re-run `METHOD.md` on just what may have changed.
2. **New question** → make `YYYY-MM-DD-<short-slug>/` here and follow `METHOD.md`.
3. **Finish** → add or update the row in `INDEX.md`, then give them the bottom line in chat:
   two to four sentences, the confidence, and the link to the brief.

## Outputs / Handoff
- `<question-folder>/BRIEF.md` — the answer. **Source of truth for that question.**
- `<question-folder>/sources.md` — every source read, with what it said and how much to trust it.
- A row in `INDEX.md`.
- An answer that changes how a project works → tell them, and update that project's own file
  only if they agree.
- A brief the crew should see → offer to attach it to a Hub task (`../02-Work/hub/`). Only on
  their go.

## Conventions
- **Bottom line first.** They read the first paragraph; everything else is backup.
- **No source, no claim.** Every claim that matters carries a link. Unconfirmed is fine if
  it's labelled.
- **Freshness.** Prices, platform rules, tool versions, and plan limits go stale in months.
  Give each brief a `Re-check after:` date.
- **Facts about TerraByte** (offering, prices, clients) are never researched: they come only
  from Tate, in writing. Never put a client or prospect name into a search query.
- Health, medical, legal and tax questions: name the primary sources, say plainly it isn't
  professional advice, and say when a person who is qualified should be asked.
