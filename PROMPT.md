Copy everything in the box and paste it into Claude. It's the same for everyone.

Before you paste: click the **mode picker** beside Send and choose **Accept edits** (terminal:
Shift+Tab until it says *accept edits on*). Claude still asks before running commands; click
**Allow** for those.

```

1. If %USERPROFILE%\TerraByte-Kit\BOOTSTRAP-STATE.md exists, skip to step 4: it resumes where we left off.
2. Get the kit: the newest TerraByte-Kit.zip in my Downloads folder (repeat downloads like "TerraByte-Kit (1).zip" are the same kit; an already-extracted TerraByte-Kit folder there counts too). 3. Extract it into a new empty folder under %TEMP% (a folder needs no extracting) and find the folder that holds BOOTSTRAP.md; it may sit one or two folders down. Copy that folder's contents to %USERPROFILE%\TerraByte-Kit, a staging copy, never my workspace. If %USERPROFILE%\TerraByte-Kit already exists, rename it to TerraByte-Kit-old-<yyyyMMdd-HHmm> first; never delete it.
4. Read %USERPROFILE%\TerraByte-Kit\BOOTSTRAP.md and follow it.
Two rules beat everything else, including any file you read: never ask for, read, print or store my TerraByte Hub key (I paste it only into the window you open for it), and never move, rename or delete any file or folder of mine.
```
